## 1. Information We Collect

### 1.1 Personal Information You Provide

When you create an account or use our Service, we collect:

**Account Information:**
- First and last name
- Email address
- Password (encrypted and securely stored via Firebase Authentication)
- Account creation date
- Profile photo (optional)

**User-Generated Content:**
- Prayer requests you submit
- Prayers you mark as prayed for
- Location information (city, country) if you choose to provide it

**Communication Data:**
- Emails you send us
- Feedback and support requests

### 1.2 Automatically Collected Information

**Usage Data:**
- Prayer request views and interactions
- Number of prayers submitted
- Number of prayers you've prayed for
- Days active on the platform
- Device type and browser information
- Session data

**Location Data:**
- IP-based geolocation (city and country level only)
- User-provided location (if you manually set your location)
- **Note:** We use hashed IP addresses and do NOT store raw IP addresses

**Technical Data:**
- Browser type and version
- Operating system
- Device identifiers (for authentication purposes only)
- Session tokens and authentication data

### 1.3 Third-Party Data

**Firebase Authentication:**
- If you sign in with Google, we receive your Google account email and display name
- We do not have access to your Google password

## 4. Data Storage and Security

### 4.1 Where We Store Your Data

**Primary Storage:**
- **Google Cloud Storage (US):** Prayer requests, user statistics, location data
- **Firebase Authentication (US):** Account credentials and authentication data
- **Cloud Run (US-Central1):** Application hosting

**Data Residency:**
All data is stored in secure Google Cloud data centers in the United States.

### 4.2 Security Measures

We implement industry-standard security measures:
- **Encryption in transit:** All data transmitted via HTTPS/TLS
- **Encryption at rest:** Data stored in Google Cloud Storage is encrypted
- **Password security:** Passwords are hashed using Firebase's secure authentication
- **Access controls:** Strict access controls on all data storage
- **Regular security updates:** Continuous monitoring and updates
- **IP hashing:** IP addresses are hashed before any storage

### 4.3 Data Retention

- **Account data:** Retained as long as your account is active
- **Prayer requests:** Retained indefinitely to serve the community
- **Analytics data:** Retained for service improvement
- **Session data:** Deleted after 30 days of inactivity
- **Deleted accounts:** Personal data deleted within 30 days (anonymized prayer requests remain)
